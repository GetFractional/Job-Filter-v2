# Job Filter v2 MCP Map

- GitHub:
  - code
  - branches
  - PRs
  - repo docs
- ClickUp:
  - tasks
  - milestones
  - implementation governance
  - sync receipts
- Airtable:
  - Job Filter tracker
  - structured data tasks
- Figma:
  - design references after requirements are explicit
- Playwright:
  - UI QA after a flow is ready
  - keep screenshots scoped to the flow under test
- Memory MCP:
  - compact packet handoffs
  - QA verdicts
  - durable decisions

Do not duplicate tracker truth across ClickUp, Airtable, and Memory.
