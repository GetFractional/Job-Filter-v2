## 5) Positioning / Value Prop / USP Ladder

Positioning:
- Job Filter helps experienced operators pursue fewer, better-fit roles by combining profile setup, targeting, and transparent draft context.

Value prop ladder:
1. Better-fit role selection
2. Faster tailoring with less rewriting
3. Stronger, consistent positioning across assets
4. Clear confidence cues on what each draft used

USP ladder:
1. Guided profile setup that becomes reusable context.
2. Targeting-first flow that shapes job feed quality.
3. Transparent draft context panel (`Why this draft`).
4. Premium strategic path (Research / Growth Plan) after setup and job selection.

Primary CTA selection decision:
- Option chosen from candidate set: `Build my 2026 job profile`.
- Reason: highest mechanism clarity with explicit setup intent and 2026 recency cue.

- `Save and continue` or `Generate first draft` depending on stage.

Framework selection for CTA and headline direction:
- Primary: StoryBrand (hero=user, product=guide, mechanism-first CTA)

- Supporting: Alen Certainty Building (explicit next-step language and trust cues)

## 9) Motion + Accessibility Rules

Motion:
- Opacity + slight translate only.
- Duration 150ms to 220ms.
- No layout-shifting animation.
- Respect `prefers-reduced-motion`.

Accessibility:
- Contrast at least WCAG AA.
- Focus states visible on all interactives.
- Touch targets >=44px on mobile.
- Status messages should be clear and actionable.
