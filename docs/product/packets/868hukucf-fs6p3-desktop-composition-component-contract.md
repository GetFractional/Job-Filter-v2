### Header and subheader rhythm inside product windows

- route label line sits above the page title only on `Profile`, `Jobs`, and `Applications`

- local progress, when present, sits below the route title block with `16px` separation

### Full-width versus split-layout rule

- full-width only when the core task is list-first and the secondary context is lightweight
- split layout when the user needs to compare work against support context without losing flow
- right rails are not used for decorative summaries
- a right rail must either explain the current decision or hold the next-useful support object

- table headers are always visible without scrolling out of the viewport
- controls use compact labels and never become large chips
