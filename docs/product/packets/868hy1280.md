## Acceptance Criteria

- User can import seeded demo material or start manually, then confirm identity and contact details.
- User can select a role lane and see why that lane fits.
- User can review extracted stories and approve which ones are eligible for asset generation.
- User can review metrics and claim safety so only defensible proof is used downstream.
- User can enter one target job and generate a reviewable resume and cover letter from approved context.
- Generated outputs use safer fallback phrasing when metric confidence is lower and exclude unsupported claims.
- Flow persists across reloads and can resume mid-process.
- Existing prototype surfaces are reused where sensible instead of rebuilt greenfield.
