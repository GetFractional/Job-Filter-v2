Foundation Series 04B Website mobile artifact packet

05. Website and Public Funnel, Mobile

This file translates the approved website funnel into mobile-first page artifacts. It keeps the same page set, CTA hierarchy, proof architecture, worksheet placement, and auth-to-Profile handoff as the desktop packet.

Core pages represented

Home, How It Works, Pricing, Job Profile Worksheet landing page, and Auth in create-account and sign-in states.

Carry-forward rules

`Build my job profile` stays primary, `See how it works` stays exploratory, and `Continue setup` remains inside the signed-in continuation path.

What this packet avoids

No standalone Product, Proof, or FAQ pages. No activation layouts. No generic dashboard destination in the auth path.
